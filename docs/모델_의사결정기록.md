> 모델마다 "왜 지금 방법을 택했는가"를 스펙 → 구현 시도 → 어려움 → 최종 결정 순서로 정리한 기록. 각 항목에 **근거 출처**를 붙였고, 문서 근거가 없는 팀의 구두 설명은 `[팀 구두 설명]`으로 표시했다.
