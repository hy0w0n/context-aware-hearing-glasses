1단계: 프로젝트 내 컴퓨터로 가져오기 (Clone)

안드로이드 스튜디오를 켭니다. (열려있는 프로젝트가 있다면 File -> Close Project를 눌러 첫 화면으로 갑니다.)

시작 화면에서 Get from VCS (또는 Clone from Version Control) 버튼을 클릭합니다.

URL 칸에 우리 팀의 깃허브 저장소 주소를 붙여넣기 합니다.

주소 : https://github.com/hy0w0n/SmartHearing_Edge.git

Clone 버튼을 누릅니다.


2단계: 🚨 필수 도구 설치하기 (매우 중요)

이 프로젝트는 Edge Impulse의 인공지능 C++ 코드를 사용하고 있습니다. 따라서 빌드를 위해 두 가지 도구를 반드시 설치해야 합니다. (이걸 안 하면 빨간 에러가 뜹니다!)

안드로이드 스튜디오 상단 메뉴에서 Tools ➡️ SDK Manager를 클릭합니다.

창이 열리면 중간의 SDK Tools 탭을 클릭합니다.

아래 목록을 스크롤하여 다음 2가지 항목에 체크(✔)합니다.

NDK (Side by side) -> 28.2.13676358버전

CMake

우측 하단의 Apply를 누르고 설치가 완료될 때까지 기다린 후 Finish를 누릅니다.

3단계: 로딩 기다리기 (Gradle Sync)

도구 설치가 끝나면 안드로이드 스튜디오 오른쪽 아래에 로딩 바가 열심히 돌아가고 있을 것입니다. (코드를 내 컴퓨터에 맞게 세팅하는 과정입니다.)

보통 1~3분 정도 걸립니다. 가만히 기다려 줍니다.

혹시 우측 상단에 코끼리 모양 아이콘(🐘 Sync Now)이 떠 있다면 한 번 눌러주세요.

하단에 BUILD SUCCESSFUL 이 뜨면 완벽하게 준비된 것입니다!

4단계: 앱 실행하기 (Run)

테스트할 안드로이드 스마트폰을 컴퓨터에 USB로 연결합니다. (또는 안드로이드 에뮬레이터를 켭니다.)

안드로이드 스튜디오 상단 중앙에 내 스마트폰 이름이 잘 뜨는지 확인합니다.

그 옆에 있는 초록색 재생 버튼(▶ Run 'app')을 클릭합니다.

잠시 후 스마트폰에 앱이 설치되고 실행됩니다! 자유롭게 테스트해보세요
